# Darts Arena – Download für Windows

> Alpha-Version: Es kann noch Fehler geben. Bitte melde dem Entwickler, was dir auffällt.

**[Darts-Arena-Setup.exe herunterladen](https://github.com/hsnowmansch/darts-arena-releases/releases/latest/download/Darts-Arena-Setup.exe)**

Alle Versionen stehen unter [Releases](https://github.com/hsnowmansch/darts-arena-releases/releases).

## Installieren

1. Doppelklick auf die heruntergeladene Datei.
2. Zeigt Windows „Der Computer wurde durch Windows geschützt“, ist das normal (die Alpha ist nicht von Microsoft signiert):
   Klicke auf **„Weitere Informationen“** und dann auf **„Trotzdem ausführen“**.
3. Die Installation läuft von selbst. Danach startet **Darts Arena**.

## Voraussetzung

**Autodarts Desktop** mit eingerichtetem Dartboard. Oben rechts in der App steht dann **„Board bereit“**.
